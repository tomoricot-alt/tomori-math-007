# TOMORI MATH 使い方

小学3・4年生が、一人でできる算数の練習アプリです。

## はじめかた

1. **学年**をえらびます（3年生 / 4年生）。
2. **けいさん**をえらびます（たし算・ひき算・かけ算・わり算・ミックス）。
3. **レベル**をえらびます（やさしい・ふつう・チャレンジ）。
4. **こたえかた**をえらびます（えらぶ / 数字を入れる）。
5. 「スタート！」を押します。

## 問題の画面

- 1画面に1問ずつ出ます。上に「3 / 10」のように、いま何問目か出ます。
- **えらぶ**：4つの数字から、答えをタップします。
- **数字を入れる**：画面の数字ボタンで答えを入れて、「こたえる」を押します。「⌫」で1文字消し、「消す」で全部消せます。（パソコンでは、キーボードの数字と Enter も使えます。）
- 正解すると、お祝いのアニメーションが出ます 🎉
- まちがえても大丈夫。正しい答えが出るので、見てから「つぎへ」を押します。
- 「やめる」でホームにもどれます（その回は記録されません）。

## 結果の画面

- 「10問中 ○問 せいかい」と、星（★）で達成状況が出ます。
  - 10問ぜんぶ：★★★ ／ 7〜9問：★★☆ ／ 4〜6問：★☆☆ ／ 0〜3問：がんばり中の ☆
- まちがえた問題と正しい答えが一覧で出ます。
- 「まちがえた もんだいを やりなおす」で、その問題だけをもう一度解けます。
- 「もういちど 10問」で、同じ設定の新しい10問に挑戦できます。

## きろく

- ホームの「きろくを見る」で、これまでの練習（日時・学年・計算・レベル・点数）が見られます。
- 1回分をタップすると、まちがえた問題が出ます。「この もんだいを ふくしゅう」で復習できます。
- 「きろくを けす」で、きろくをぜんぶ消せます。

## 問題のきまり

- わり算は、ぴったり割り切れる問題だけが出ます（あまりは出ません）。
- ひき算の答えは、マイナスになりません。

## 注意

- きろくは、いま使っている端末・ブラウザの中だけに保存されます。ほかの端末とは共有されません。
- ブラウザのデータ（サイトデータ）を消すと、きろくも消えます。
- 名前や学校名などは入力しません。ログインも、ネットへの送信もありません。
